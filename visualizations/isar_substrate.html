ISAR Substrate — Interactive Walkthrough

The four-carrier rank-4 kernel (Invariant · Rewrite · Adjacency · State), shown live as kernel matrices, a relational node graph (IOB), and a sparse compute tensor (U) — followed by a parallel reduction, a distributed merge, and a tensor↔text codec with diffing.

1 · ISAR Kernel — the four axiomatic matrices

Each carrier is a 4×4 matrix. Together they form the rank-4 tensor K = [I,R,A,S]. This is fixed at boot — axiomatic, never mutated, ~256 bytes total.

Click any cell to toggle it and see how the composite invariant signature (hash) changes — this models how a single bit-flip in the axioms invalidates the whole substrate's identity.

Rank-4 sparse COO: (i,s,a,r,value). This is C_R / C_S in motion — the only table that gets hot, parallel, GPU-bound writes.

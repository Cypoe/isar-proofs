Compact opening

I did not start with a grand theory. I started with a practical problem: a place to store ideas and artifacts, and a growing suspicion that many different descriptions were secretly preserving the same structure. That suspicion first appeared in encodings, then in invariants, then in quantity-calculus-style reasoning about what survives relabeling, and eventually in a bootstrap result: many distinct formal systems can be understood as different presentations of one invariant layer.

Quantity as first hook

Quantity calculus should come early because it is the cleanest place where readers already accept the core idea: the object is not the notation. “5 kilograms” and “5000 grams” are different surface forms of the same quantity relation, which makes dimensional structure the first accessible example of invariant thinking. [cite:117]

What people know

Changing units changes the description, not the thing measured. [cite:117]

5 kg = 5000 g
1 m = 100 cm
Real-life analogy

A road is not made longer because a map switches from miles to kilometers. The labels move; the relation stays. [cite:117]

Formal result

This becomes the first quotient-style discipline: admissible transformations preserve dimensional relations, so the relational object matters more than the particular notation. [cite:117]

Why it belongs here

Quantity calculus is the first place where the reader already believes the theorem informally. They already know: the same quantity can wear different units So the paper can say: representation != object preserved relation = object of interest That makes later claims about syntax, rewriting, and dialect translation feel like generalizations of something ordinary rather than alien abstractions. Encodings and invariants

The layman hook is simple: a document can survive renaming, recompression, or format conversion. The formal move is to stop treating that as folklore and instead define the observational equivalence under which those surface changes are declared irrelevant. [cite:118][cite:119][cite:121]

What people already believe

rename(file) = same content
zip(file) = same document, new encoding
screenshot(pdf) ≈ same visible content

Everyday computing already assumes an invariant object beneath changing representations. [cite:117][cite:118]

Formal compression

Fix an observational equivalence: x ~ y iff they preserve the same admissible behavior Then define: invariant object = equivalence class [x] This is the paper move: not “many formats are convenient” but “many formats are views of the same quotient object” [cite:121][cite:119]

One-line bridge

Once the right observational equivalence is fixed, the quotient is no longer a convenience for the analyst; it is the canonical object that all admissible views must respect. [cite:121][cite:119]

Self-hosting and quines

The quine point should not read as a magic trick. The useful insight is that self-description exposes dependency structure: what is genuinely closed under self-application, what still leans on a host language, and where the bootstrap boundary actually lives. That is the stronger and more honest story for Plex and the monograph. [cite:113][cite:122][cite:123]

What people know

A manual can describe how to build the machine that prints the manual. A compiler can compile a compiler. [cite:113]

Real-life analogy

The interesting question is not whether something can copy itself, but what substrate it still depends on while doing so. [cite:122]

Formal reading

Self-application is informative because it reveals hierarchy and bootstrap structure. It distinguishes trivial reproduction from a genuinely closed semantic substrate. [cite:113][cite:122]

Recommended framing

Do not say: “quine = miracle” Say: self-description revealed the bootstrap layer Then separate: theorem = view-independent rewrite kernel runtime = implementation target language = still an open design surface That matches the project split: ISAR is the kernel theorem Plex is the family of practical dialects and runtimes. [cite:122][cite:123]

Intro paragraph

I did not start with a theory of computation or physics. I started with a place to store things, and then noticed that every useful representation preserved some structure while hiding other structure. That simple observation led first to encodings, then to invariants, then to a quantity-calculus-style way of treating relational structure as primary, and eventually to a bootstrap result: many different formal systems can be seen as different presentations of the same invariant layer. This paper develops that pattern formally. We define an observational equivalence on admissible representations, show how normal forms and quotients make representation-independent behavior explicit, and prove that a broad class of encodings factor through a common invariant layer.

Arc sentence

We began with representations, noticed invariants, rediscovered quantity calculus from first principles, and ended with a minimal quotient structure through which many systems — from rewriting to self-hosting to physical quantities — factor uniquely. [cite:117]

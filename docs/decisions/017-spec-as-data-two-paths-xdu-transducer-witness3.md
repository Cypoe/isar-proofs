**(1) The toolchain spec is declarations-only JSON.** `host/toolchain.json` holds dialects, ISAs, routine sets, targets, pieces, the two realization `paths`, strategy axes (incl. a named `geometry` group), observation `regimes`, and per-gate `obligations`. **(2) The two paths are disjoint realizations of one declaration.** `native`: the program (a plex declaring its own byte-level behaviour) compiles to code — no reducer, no tags, no ISAR terms in the image. `runtime`: the same declaration encodes to a basis term reduced live by a piece. Equivalence is `stdout bytes + rc`, not NF spelling alone. The first program class is **finite nibble transducers** (`programs/xdu/*.json`: states × nibble/`$in`/`*` → emit/next/eof-halt). `xdu_gate.py` (lead-authored) runs direct table-walk == native exe == graph.lo == graph.cd on a corpus crossing the 64 KiB read granule — 73/73 cells. G8b forbids reducer labels/imports in the image; G8c rebuilds at `read_buf_bytes=1024` with identical observations (granule-immediates-only diff).

**(3) Two plan sketches were falsified in implementation, both documented in place.** (a) `S h t` is NOT an inert output spine on the runtime path — graph.lo expands S to `derived_s`, which keeps reducing; the spine uses `C h t` (swap needs a 3rd arg everywhere realized). (b) a Y-fixpoint transducer DIVERGES under `graph.cd` — complete development re-develops the self-reproducing redex inside dead selector arms; replaced by bounded Church-numeral iteration (`n STEP acc0`), which reaches its cd fixpoint. Last spine element = halt rc; odd output-nibble count drops the pending nibble and overrides rc to 3 — one declared convention in `term_to_nibbles`, `interpret`, and the native `pend` slot alike.

**(4) The ISA encoder is table-driven (fasmg discipline).** `isa_x86_64.py` `ENCS` rows are ordered `(predicates → field-ops)` data; `_interpret` (~10 lines) knows only field/predicate NAMES — zero instruction-family branching. Quirks are named predicates (`i8` shrink, `acc`, `i32` sign-ext); the spl..dil/r8b+ REX quirk lives in the `rex` field. Byte-identical images both builds, 65 fasmg samples — incl. 5 new ones that caught two latent REX bugs in unexercised combos. Honest bound: the field vocabulary is x86 data; only a second ISA proves the seam. Latent footgun recorded: `("p",label)` operands resolve only in dedicated rip/rel forms — elsewhere they silently encode disp=0.
